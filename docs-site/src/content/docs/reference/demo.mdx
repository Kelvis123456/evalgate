Everything below is the real output of the commands shown, run from the repository root against the committed `baseline.json` (2026-11-05, Windows, Python 3.14). The numbers are deterministic for the reference app, so you get the same ones. The tables were re-run while writing this site and match the repository's `docs/demo-regression.md`, including the `citation_precision` row.

`main` stays green: the degraded settings are passed on the command line and are never committed.

```sh
pip install -e ".[dev]"
evalgate run                                    # exit 0
evalgate run --param tokenizer=whitespace       # exit 1
evalgate run --param top_k=1                    # exit 1
evalgate run --param min_coverage=0.9           # exit 1
```

`--param` passes keyword arguments to the app factory, so the same trick works for your own app. The reference corpus is 25 passages about a made-up job-queue product, retrieved with a stdlib BM25 index and answered by picking the sentence that covers the most query terms.

Note that `abstention_accuracy` went up. An app that finds nothing refuses everything, which looks good on that one metric. This is why the gate checks every metric in the baseline instead of one headline score.
